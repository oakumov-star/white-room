WHITE ROOM — первая версия PWA

Содержимое:
- index.html — приложение
- manifest.json — настройки установки
- sw.js — офлайн-кэш

Как открыть на iPhone:
1. Размести папку на HTTPS-хостинге (например, GitHub Pages или Netlify; можно бесплатно).
2. Открой опубликованный HTTPS-адрес в Safari.
3. Нажми «Поделиться» → «На экран Домой» → «Добавить».
4. Запускай приложение с иконки.

Данные хранятся локально в браузере на устройстве. В настройках есть экспорт резервной копии.
Важно: напоминание в этой версии работает, пока приложение открыто. Надёжные фоновые push-уведомления на iPhone требуют отдельной push-инфраструктуры и настройки.

Первая версия включает:
- отметки привычек, добавление привычек;
- XP и уровни;
- календарь;
- статистику за 7 дней и общий процент;
- цели и достижения;
- заметки дня;
- гибкое время дня;
- экспорт и сброс данных.
